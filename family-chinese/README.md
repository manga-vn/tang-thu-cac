# 🀄 Ba Cha Con Học Tiếng Trung

Web app học tiếng Trung dành riêng cho gia đình — 3 profile, từ vựng chung, flashcard cá nhân.

## Chạy app

```bash
cd family-chinese
npm install       # lần đầu tiên
npm run dev       # mở http://localhost:5173
```

## Tính năng

- Chọn profile: Cha / Con 1 / Con 2
- Dashboard: từ mới nhất + ai đã ôn hôm nay
- Ôn bài (Flashcard): lật thẻ, đánh dấu Nhớ / Chưa nhớ
- Từ vựng: danh sách, tìm kiếm, lọc nhãn
- Thêm từ: chỉ Cha mới thấy tab này

## Dữ liệu

Lưu trong localStorage — không cần server, không cần internet.
